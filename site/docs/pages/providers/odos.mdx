# Odos (deprecated)

<Callout type="warning">
  Odos is shutting down. The `odos()` provider remains available temporarily so existing
  applications continue to start, but constructing it logs a deprecation warning and every quote
  fails immediately without making a network request. Remove it from your provider configuration.
</Callout>

## Migration

```ts twoslash
import { createConfig, nordstern } from "@spandex/core";

export const config = createConfig({
  providers: [
    nordstern({}),
    // Add other active providers here.
  ],
});
```
