Set `DRPC_API_KEY` in your environment or in `examples/hono/.env` for testing and running the demo. Base and Unichain use authenticated dRPC when the key is set, or public dRPC when it is omitted. No other RPC providers are used.

To install dependencies:
```sh
bun install
```

To run:
```sh
bun run dev
```

open http://localhost:3000
